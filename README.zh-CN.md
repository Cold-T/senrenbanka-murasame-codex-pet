# 丛雨 Codex Pet

一个基于《千恋＊万花》丛雨的非官方 fan-made Codex pet。

## 预览

这个 pet 包含 Codex 兼容的动画精灵图，覆盖以下状态：

- idle
- running-right
- running-left
- waving
- jumping
- failed
- waiting
- running
- review

## 安装

克隆或下载这个仓库，然后把 `murasame` 文件夹放到你的 Codex pets 目录：

```bash
mkdir -p ~/.codex/pets
cp -R murasame ~/.codex/pets/
```

最终目录结构应为：

```text
~/.codex/pets/murasame/
  pet.json
  spritesheet.webp
```

重启或刷新 Codex，然后在 pet 选择器里选择 `丛雨`。

## 文件

- `murasame/pet.json`：Codex pet 清单文件。
- `murasame/spritesheet.webp`：8 x 9 的 Codex pet 动画图集。
